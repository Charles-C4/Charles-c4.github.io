Welcome to the source code for my personal portfolio website. This single-page application showcases my journey as a Cloud & DevOps Engineer, SRE, and Entrepreneur. It highlights my projects (including BetProtector), technical skills, and professional experience.

## 🔗 Live Demo
Visit the live site here: **https://charles-c4.github.io**


## 🛠️ Tech Stack
This portfolio is built with a focus on simplicity, performance, and modern aesthetics.
* **Structure:** HTML5 (Semantic)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (loaded via CDN for lightweight deployment)
* **Interactivity:** Vanilla JavaScript (Typing effects, Mobile Menu)
* **Icons:** FontAwesome 6
* **Fonts:** Inter (Sans) & Fira Code (Mono/Coding style)

## ⚡ Features
* **Responsive Design:** Fully adaptive layout for Mobile, Tablet, and Desktop.
* **Glassmorphism UI:** Modern translucent cards using backdrop-blur effects.
* **Terminal Aesthetic:** Monospace fonts and dark theme to reflect a DevOps engineering environment.
* **Single File Architecture:** No complex build steps or `node_modules` required—just raw, efficient code.

## 🚀 How to Run Locally
Since this project uses the Tailwind CDN, you don't need to install any dependencies (`npm`, `yarn`, etc.).

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/charles-c4/portfolio.git](https://github.com/charles-c4/portfolio.git)
    ```
2.  **Navigate to the folder:**
    ```bash
    cd portfolio
    ```
3.  **Open in Browser:**
    Simply double-click `index.html` or run it with a live server extension in VS Code.
